# Monitorture

**Because choosing a monitor is hard.**

Monitorture is a browser-based toolkit for anyone choosing, comparing, or testing computer monitors. It draws true-to-scale side-by-side comparisons of different screen sizes, resolutions, aspect ratios, and curvatures (front and top-down views, with an optional desk overlay), and includes full-screen test patterns for checking a display's pixels, uniformity, gradients, gamma, and geometry. Pick from generic monitor classes or specific real-world models, or enter your own — everything runs client-side, no install required.

**Live:** https://monitorture.com
